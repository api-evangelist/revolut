# Revolut

> Revolut is a global financial technology company offering banking, payments, cards, foreign exchange, and crypto services. Its developer platform exposes several REST APIs: the Business API (accounts, payments, counterparties, cards), the Merchant API (online card acquiring / checkout), the Open Banking API (UK Open Banking / PSD2 AISP + PISP), the Crypto Ramp API (fiat-to-crypto on/off ramp), and the Revolut X crypto exchange API.

## APIs
- [Business API](https://developer.revolut.com/docs/business/business-api): Accounts, transfers, payments, counterparties, cards, webhooks. OAuth 2.0. Host b2b.revolut.com/api/1.0.
- [Merchant API](https://developer.revolut.com/docs/merchant/merchant-api): Online payment acceptance, orders, captures, refunds, subscriptions, webhooks. Secret API key. Date-versioned. Host merchant.revolut.com.
- [Open Banking API](https://developer.revolut.com/docs/open-banking): UK Open Banking Read/Write v3.1.0 — account information and payment initiation. OAuth 2.0 + detached JWS (FAPI). Host oba-auth.revolut.com.
- [Crypto Ramp API](https://developer.revolut.com/docs/crypto-ramp): Fiat-to-crypto on/off ramp for partners. Bearer AccessToken. Host ramp-partners.revolut.com.
- [Revolut X API](https://developer.revolut.com/docs/revolut-x): Crypto exchange REST API — balances, orders, trades, market data. API key + HMAC signing. Host revx.revolut.com/api/1.0.
